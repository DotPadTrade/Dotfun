## Quick facts

- Every banner is a **unique composition** (no shared template), built from the
  app's real brand system (night/mint/ice palette, official logo asset).
- Every technical claim in the posts is verified against this repository.
- $RELAY is presented honestly: **no official token exists yet**; the treasury
  dashboard is **read-only**; automated buybacks/burns are **not operational**.
- No dates, prices, partnerships, audits, statistics or contract addresses were invented.
